مزودو الذكاء الاصطناعي

استخدم مفتاحك الخاص. بدّل بين المزودين في أي وقت. مفتاحك مشفر ولا يظهر أبدًا في جافاسكربت الواجهة.

المزودون المدعومون
المزودما هوملاحظات صادقة
OpenAIنماذج GPT عبر واجهة OpenAI البرمجية.تزود مفتاح API الخاص بك. يُخزَّن مشفرًا على خادمك.
Anthropicنماذج Claude عبر واجهة Anthropic البرمجية.تزود مفتاح API الخاص بك. يُخزَّن مشفرًا على خادمك.
Google Geminiنماذج Gemini عبر واجهة Google AI.تزود مفتاح API الخاص بك. يُخزَّن مشفرًا على خادمك.
Metaنماذج Meta للذكاء الاصطناعي.توفر نقاط النهاية والنماذج يختلف — تحقق من توثيق مزود Meta لديك قبل الاعتماد عليه.
مستضاف ذاتيًا / Ollamaأي نقطة نهاية متوافقة مع OpenAI تشغّلها بنفسك.بدون مفتاح. يعمل مع localhost بالتصميم — طلباتك لا تغادر بنيتك التحتية.

كيف تُدار المفاتيح

تُخزَّن مفاتيح API مشفرة في قاعدة بيانات ووردبريس، وتُستخدم على الخادم فقط عند استدعاء واجهة المزود. لا تُطبع في HTML أبدًا، ولا تُرسل إلى المتصفح، ولا تُكتب في السجلات.

كيف يعمل التبديل

أعدد أي عدد من المزودين في إعدادات الذكاء الاصطناعي، واختبر اتصال كل منهم، ثم اختر النشط لكل مهمة. تبقى تدقيقاتك وسجلك وإعداداتك كما هي عند التبديل.

ملاحظة عن Meta: نقاط نهاية Meta للذكاء الاصطناعي وتوفر النماذج تتغير مع الوقت وتختلف حسب المنطقة والحساب. تحقق من أسماء نقاط النهاية والنماذج في توثيق المزود — يتيح لك LocalBoost ضبط الرابط الأساسي واسم النموذج صراحة لهذا السبب بالذات.
ملاحظة عن النماذج المستضافة ذاتيًا: يسمح مزود الاستضافة الذاتية عمدًا باستهداف localhost / 127.0.0.1 (هذه هي فكرة Ollama). وجّهه فقط إلى نقاط نهاية تتحكم بها.
