Changelog

What shipped, what changed, and what's honestly still missing.

v1.0.0 — 24 September 2026 · Initial public release

Added

  • Download v1.0.0 — free; install via Plugins → Add New → Upload Plugin.
  • Local SEO audit with an understandable 0–100 LocalBoost SEO Score and plain-language issue explanations.
  • “Fix with AI” flow: side-by-side current-vs-suggestion preview; nothing applied without approval.
  • AI Optimizer for titles, meta descriptions, headings, introductions, FAQs and calls to action.
  • Five AI providers: OpenAI, Anthropic, Google Gemini, Meta, and keyless self-hosted / Ollama-compatible endpoints.
  • Local business profile with valid JSON-LD schema output.
  • Content and keyword assistant (ideas only — no fabricated search-volume data).
  • Monitoring with scheduled re-audits, score history, CSV reports and email notifications.
  • Seven-step onboarding, 12 admin screens, freemium usage limits with transparent quota display.
  • API keys encrypted at rest; never exposed to frontend JavaScript.

Known limitations

  • Reports export as CSV only — PDF export is not available.
  • Admin interface is English; a .pot translation template ships for translators (FR, DE, ES, IT, NL, PT planned).
  • Meta provider endpoints and model names must be verified against your provider's documentation — availability varies.
  • Pro tier is in development: no license server and no payment flow exist yet.
  • Single-site only; multisite/agency management is future work.
  • Live WordPress end-to-end testing on staging is still pending — please test on staging before production use.
